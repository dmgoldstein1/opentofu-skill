## Using This Documentation

### 1. Understanding Resources vs Data Sources

**Resources** are used to create and manage infrastructure:
```hcl
resource "vultr_instance" "web" {
  region  = "sjc"
  plan_id = "vc2-1c-1gb"
  os_id   = 387  # CentOS 7 x64
}
```

**Data Sources** are used to fetch information about existing infrastructure:
```hcl
data "vultr_instance" "web" {
  filter {
    name   = "label"
    values = ["my-instance"]
  }
}
```

### 2. Finding Resources

## Common Tasks

### Create a VPC and Instance

```hcl
resource "vultr_vpc" "example" {
  region      = "sjc"
  description = "My VPC"
}

resource "vultr_instance" "example" {
  region  = vultr_vpc.example.region
  plan_id = "vc2-1c-1gb"
  os_id   = 387
}
```

See:
- [resources/50_vpc.md](./resources/50_vpc.md)
- [resources/17_instance.md](./resources/17_instance.md)

### Query Existing Resources

```hcl
data "vultr_instance" "example" {
  filter {
    name   = "label"
    values = ["my-instance"]
  }
}

data "vultr_region" "example" {
  filter {
    name   = "country"
    values = ["US"]
  }
}
```

See:
- [data-sources/12_instance.md](./data-sources/12_instance.md)

### Setup Database

```hcl
resource "vultr_database" "example" {
  database_engine = "mysql"
  database_engine_version = "8"
  region = "sjc"
  plan_id = "vultr-dbaas-startup-cc-1-55gb"
}
```

## Important Notes

1. **Compatibility**: The Vultr provider works with both OpenTofu and Terraform
2. **API Key**: Get your API key from https://my.vultr.com/settings/#settingsapi
3. **Rate Limiting**: Default is 500ms between calls (30 calls/second max)
4. **Retries**: Default is 3 retries on failed API calls
